# MYES English

App personale per il corso di inglese MYES: glossario, ripasso a ripetizione dilazionata, schede di grammatica, diario delle lezioni e degli errori.

- Installabile su Android (Chrome → menu → *Installa app*), funziona offline.
- I dati restano nel dispositivo (IndexedDB). Sincronizzazione facoltativa tra dispositivi tramite un Gist privato di GitHub, backup su file.
- HTML, CSS e JavaScript semplici, senza build. Pubblicata con GitHub Pages.

Per rilasciare una nuova versione: aggiorna `VERSION` in `sw.js` e `APP_VERSION` in `app.js`.
